# 指标与数据状态

## 先确认单位和统计范围

| 显示 | 含义 |
| --- | --- |
| bit/s | 字节差值 × 8 / 实际采样时间 |
| PPS / packets/s | 当前统计点的包速率，不保证等于线上帧率 |
| intr/s | 硬中断处理次数速率，不是 PPS |
| 原始累计值 | 内核提供的累计计数，不一定从程序启动开始 |
| SINCE BASELINE | 当前有效基线以来的变化 |
| 当前值 | 队列、连接数、窗口、MTU 等瞬时值 |

netlens 观察当前网络命名空间；内存和 CPU 中断等部分数据属于主机范围，会单独标注。
`-i` 不把主机总计变成网口总计，不同层也不一定使用相同包计数单位。
TCP 与队列字段在对应场景页解释，避免把不同类型混为同一种口径。

## 速率、基线和缓存

按 `t` 切换间隔值与基线累计值；单个 socket 详情使用自身实时值。
首次采样只建立基线，没有速率。计数重置、设备身份变化或采集间断后重新建基线，不跨间断算差值。

采集跟随当前页面：离开某页会停止无关采集，返回后先重新建立速率基线。
空格或 `p` 只暂停显示，不停止后台采集。

配置刷新可能比流量慢，缓存值保留真实观察时间，不冒充新样本。
低频来源的速率是其采样区间的平均值，短突发可能被平滑。

## 缺失数据怎么判断

```sh
netlens providers
```

先看数据来源、错误和观察年龄，再判断业务是否异常。

| 状态 | 该怎么理解 |
| --- | --- |
| ACTIVE | 当前来源可用，不代表网络没有故障 |
| PARTIAL | 只有部分字段或条目可用 |
| DEGRADED | 采集质量下降，查看失败或过期原因 |
| UNAVAILABLE | 当前无法获取该来源 |
| UNSUPPORTED | 内核、驱动或功能不支持 |
| NO PROVIDER | 此观察点没有可用采集来源 |
| n/a | 没有该字段，不是零 |
| TRUNCATED | 表格达到保留上限，筛选结果可能不完整 |

`LIVE`、`DATA GAPS`、`NO DATA` 是采集状态，不是网络健康评级。
`signals` 统计有效的非零诊断指标；`unavailable` 统计当前不可用的摘要指标，不等于异常连接数。
零条筛选结果在不完整快照中不能证明没有匹配连接。

## 权限和命名空间

```sh
netlens
netlens
```

普通用户可以先看可见数据。进程 FD、conntrack 和 NIC 等来源可能需要额外权限；要查看其他网络命名空间，请在该命名空间内启动工具。
`hidepid`、容器权限和安全策略仍可能限制进程扫描；root 不能补齐内核未启用的功能。
需要观察别的命名空间，应在该命名空间中运行；`-i` 不是命名空间切换。

## 避免跨层相加

- 网口、qdisc、IP、TCP、softnet 和 IRQ 的统计点、单位和范围不同。
- 根与子 qdisc、重叠错误类别、iptables-nft 与原生 nftables 不直接相加。
- GRO/GSO、转发卸载、XDP 和虚拟网口会改变哪些层能看到流量。
- 缺失值、旧值、采集间断都不能当作当前零值或正常状态。

netlens 只读，不抓包、不加载 BPF，也不修改防火墙、TC、XDP、sysctl 或网卡配置。
需要逐包路径或应用 RTT 时，应使用另外的抓包、追踪或主动探测工具。
